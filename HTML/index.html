Description list

ordered term
An ordered list in HTML is used to display a list of items in a specific sequence, typically marked with numbers or letters. The ol tag is used to create an ordered list, and each item within the list is defined using the li tag.
unordered term
An unordered list in HTML is used to group a collection of items that do not have a numerical ordering. The items are typically rendered as a bulleted list.
description term
A description list in HTML is used to define a list of terms and their corresponding descriptions. It is represented by the dl tag, which stands for "description list". This tag is used in conjunction with dt (defines terms/names) and dd (describes each term/name) tags.
